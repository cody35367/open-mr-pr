# Open MR/PR Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a button to each open repository's Source Control title bar that opens the "create new merge request / pull request" page for that repository's current branch, on GitHub or GitLab (cloud or self-hosted).

**Architecture:** Two pure, VS Code-independent modules (`src/git-provider-url.js` for remote-URL parsing/building, `src/repository-resolver.js` for picking the right repository/remote/branch out of the Git extension's data) are consumed by a thin `extension.js` that wires a single command into the `scm/title` menu, so VS Code gives one independent button per open repository.

**Tech Stack:** VS Code Extension API (`vscode` module), built-in Git extension API (`vscode.git`, `getAPI(1)`), Node.js `URLSearchParams`, Mocha (`suite`/`test` globals via `@vscode/test-cli`).

**Spec:** [docs/superpowers/specs/2026-10-14-open-mr-pr-design.md](../specs/2026-10-14-open-mr-pr-design.md)

## Global Constraints

- `src/git-provider-url.js` and `src/repository-resolver.js` must have no dependency on the `vscode` module — they must be requirable and testable with plain Node/Mocha.
- Remote selection: use the remote named `origin` if present, otherwise the first remote in the list.
- Remote URL resolution: prefer `fetchUrl`, fall back to `pushUrl`.
- Host dispatch: `host === 'github.com'` → GitHub URL builder; every other host (gitlab.com and all self-hosted instances) → GitLab URL builder.
- Scheme/port: if the remote URL was already `http://`/`https://`, reuse its scheme and port verbatim. If the remote URL was SSH-style (`user@host:path` or `ssh://...`), force `https` and drop any port entirely.
- No target-branch parameter in the built URL, no default-branch detection, and no disabling of the button on the default branch — the button is always enabled and always opens the "create new" page.
- No calls to the GitLab or GitHub APIs, no authentication, no tokens — URLs are built from local git data only.
- All failure paths show a specific message via `vscode.window.showErrorMessage` prefixed with `open-mr-pr:` and then return — never throw an uncaught exception out of the command handler, never guess a fallback URL.

## Review Focus

- A repository with zero git remotes configured — `pickRemote` must return `undefined` rather than throwing, so the command can show "No git remote is configured" instead of crashing.
- A detached HEAD (no branch checked out) — `getCurrentBranchName` must return `undefined` for a HEAD with no `name`, so the command shows "No branch is checked out" instead of building a URL with `branchName === undefined`.
- A remote that has a `pushUrl` but no `fetchUrl` (or neither) — `getRemoteUrl` must fall back correctly, or return `undefined` instead of passing `undefined`/`null` straight into `parseRemoteUrl`.
- A remote URL in a format `parseRemoteUrl` doesn't recognize — it must throw a clear, specific `Error` (not a generic/cryptic one) that the command handler catches and surfaces, rather than letting an uncaught exception propagate.
- Branch names containing characters that are special in a URL (spaces, `#`, `?`, `/`) — both the GitHub and GitLab builders must produce a correctly encoded URL, including GitLab's query-string encoding path, not just GitHub's.

```js
function finalizeParsedUrl(scheme, host, port, rawPath) {
	const path = rawPath.replace(/\/+$/, '').replace(/\.git$/, '');
	return {
		scheme,
		host,
		port: port ? Number(port) : undefined,
		path
	};
}

function parseRemoteUrl(remoteUrl) {
	const url = remoteUrl.trim();

	let match = url.match(/^ssh:\/\/(?:[^@/]+@)?([^/:]+)(?::(\d+))?\/(.+)$/);
	if (match) {
		return finalizeParsedUrl('https', match[1], undefined, match[3]);
	}

	match = url.match(/^(https?):\/\/([^/:]+)(?::(\d+))?\/(.+)$/);
	if (match) {
		return finalizeParsedUrl(match[1], match[2], match[3], match[4]);
	}

	match = url.match(/^(?:[^@/]+@)?([^:/]+):(.+)$/);
	if (match) {
		return finalizeParsedUrl('https', match[1], undefined, match[2]);
	}

	throw new Error(`Unrecognized git remote URL: ${remoteUrl}`);
}

module.exports = {
	parseRemoteUrl
};
```

```js
function encodeBranchForPath(branchName) {
	return encodeURIComponent(branchName).replace(/%2F/g, '/');
}

function buildGitHubUrl(scheme, authority, path, branchName) {
	return `${scheme}://${authority}/${path}/pull/new/${encodeBranchForPath(branchName)}`;
}

function buildGitLabUrl(scheme, authority, path, branchName) {
	const params = new URLSearchParams({ 'merge_request[source_branch]': branchName });
	return `${scheme}://${authority}/${path}/-/merge_requests/new?${params.toString()}`;
}

function buildMrPrUrl(parsed, branchName) {
	const { scheme, host, port, path } = parsed;
	const authority = port ? `${host}:${port}` : host;
	if (host === 'github.com') {
		return buildGitHubUrl(scheme, authority, path, branchName);
	}
	return buildGitLabUrl(scheme, authority, path, branchName);
}
```

```js
function pickRemote(remotes) {
	return remotes.find((remote) => remote.name === 'origin') || remotes[0];
}

function getRemoteUrl(remote) {
	return (remote && (remote.fetchUrl || remote.pushUrl)) || undefined;
}

function getCurrentBranchName(head) {
	return (head && head.name) || undefined;
}

function findRepositoryByRootUri(repositories, rootUri) {
	return repositories.find((repo) => repo.rootUri.fsPath === rootUri.fsPath);
}

module.exports = {
	pickRemote,
	getRemoteUrl,
	getCurrentBranchName,
	findRepositoryByRootUri
};
```

Replace the entire contents of `extension.js` with:

```js
const vscode = require('vscode');
const { parseRemoteUrl, buildMrPrUrl } = require('./src/git-provider-url');
const {
	pickRemote,
	getRemoteUrl,
	getCurrentBranchName,
	findRepositoryByRootUri
} = require('./src/repository-resolver');

function getGitAPI() {
	const gitExtension = vscode.extensions.getExtension('vscode.git');
	return gitExtension.exports.getAPI(1);
}

async function openMrPr(sourceControl) {
	const rootUri = sourceControl && sourceControl.rootUri;
	if (!rootUri) {
		vscode.window.showErrorMessage('open-mr-pr: Could not determine which repository to use.');
		return;
	}

	const git = getGitAPI();
	const repository = findRepositoryByRootUri(git.repositories, rootUri);
	if (!repository) {
		vscode.window.showErrorMessage('open-mr-pr: Could not find a matching git repository.');
		return;
	}

	const branchName = getCurrentBranchName(repository.state.HEAD);
	if (!branchName) {
		vscode.window.showErrorMessage('open-mr-pr: No branch is checked out (detached HEAD).');
		return;
	}

	const remote = pickRemote(repository.state.remotes);
	const remoteUrl = getRemoteUrl(remote);
	if (!remoteUrl) {
		vscode.window.showErrorMessage('open-mr-pr: No git remote is configured for this repository.');
		return;
	}

	let parsed;
	try {
		parsed = parseRemoteUrl(remoteUrl);
	} catch (error) {
		vscode.window.showErrorMessage(`open-mr-pr: ${error.message}`);
		return;
	}

	const url = buildMrPrUrl(parsed, branchName);
	await vscode.env.openExternal(vscode.Uri.parse(url));
}

function activate(context) {
	const disposable = vscode.commands.registerCommand('open-mr-pr.openMrPr', openMrPr);
	context.subscriptions.push(disposable);
}

function deactivate() {}

module.exports = {
	activate,
	deactivate
};
```
